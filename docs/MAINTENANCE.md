# 项目架构与产物维护

## 固定目录

| 位置 | 内容与维护方式 |
| --- | --- |
| 根目录 `README.md` | 当前能力、常用入口及文档导航 |
| 根目录 `AGENTS.md` | 供后续开发代理读取的维护约定 |
| `moreact/` | 可复用的数据、模型、训练、生成与评估代码 |
| `configs/` | 可复用实验配方；保留 `smoke.yaml`，它是配方，不是垃圾产物 |
| `scripts/` | 可重复运行的工具；一次性诊断脚本放 `tmp/` |
| `tests/` | 可重复的自动化测试；测试数据使用 `tmp_path` |
| `assets/` | 小型受维护资产，例如经过审核的角色修正 |
| `docs/` | 架构、接口、使用说明及维护规范 |
| `docs/reports/<日期>_<主题>/` | 持久实验报告及必要的轻量证据 |
| `tmp/<日期>_<主题>_<唯一ID>/` | smoke、预检、临时脚本、临时缓存与预览；任务结束后按下述流程清理 |
| `runs/<实验名>/` | 正式训练配置、日志、状态、checkpoint；不按名字或年龄自动删除 |
| `data/` | 正式可复用预处理数据；临时小样本缓存放该次 `tmp/` 内 |
| `outputs/<实验名>/` | 正式评估和需要保留的可视化；临时预览放该次 `tmp/` 内 |

LICENSE、NOTICE 和构建配置留在根目录。`tmp/`、`runs/`、`data/`、`outputs/` 及解释器/测试缓存
不进入版本控制；`docs/reports/` 中的报告和轻量证据应纳入版本控制。Git ignored/untracked
不等于可以删除，本项目当前仍有尚未提交的源码。

## 每次临时实验的生命周期

1. 使用独立任务目录，记录目的、命令、配置、数据/权重来源及起止时间。禁止往正式运行目录写 smoke checkpoint。
2. 结束后先在 `docs/reports/` 写明结果、失败原因、关键指标、适用边界和复现命令。
   保存配置、必要日志/JSON 指标；权重和视频仅在确实需要复核或作为后续输入时保留，并在报告中说明位置和理由。
3. 删除前检查进程命令、工作目录和打开文件，并检查保留实验的配置/来源引用。使用精确路径清单，拒绝软链接跳转及跨项目清理。
4. 报告与证据保存成功后，删除已结束且无依赖的临时权重、缓存、视频、一次性脚本和目录。
   报告记录删除清单、大小及处理结果；不为了“归档”再复制一份全部大型产物。
5. 更新仍指向旧位置的文档。历史配置保留原始内容供溯源，但明确其引用的临时文件可能已清理；不冒充可直接运行的当前配置。

已通过且无依赖的 smoke 不长期保留。失败任务暂留原目录，便于定位；修复或放弃后补齐报告再清理。
正在运行、被 watcher 等待、作为恢复来源或后续输入的文件保留，即使目录名含 smoke/preflight。
不执行全仓 `git clean -fdx`、按 `*smoke*` 通配删除、或清空 `runs/`/`data/`。
活跃训练中的 `.tmp` 文件可能属于原子 checkpoint 写入过程，不作为垃圾删除。

## smoke 的统一入口

在项目根目录运行：

```bash
MOREACT_PYTHON=/data/users/autovla/.envs/remogen-motion-only/bin/python bash scripts/smoke.sh
```

脚本委托 `scripts/run_smoke.py`，每次建立唯一 `tmp/smoke_*` 工作目录：小样本数据、训练权重、
pytest 临时文件、评估和预览均写在本次目录。`configs/smoke.yaml` 的缓存路径由入口覆盖。
原配置文件保留为可复用配方，直接手动使用它时需要自行遵守归档和清理规则。

每次运行向 `docs/reports/<运行ID>/` 写入 `README.md`、`run.json` 及轻量 `evidence/`。
全部命令成功且归档成功后，只删除本次创建的临时目录；失败或中断保留工作目录并返回非零状态。
SIGKILL/断电无法执行退出归档，恢复后按手工流程处理遗留目录。
报告保存原始命令与退出码；删除临时权重后，复现应重新执行入口，不能直接引用历史临时 checkpoint。

smoke 包含 GPU 训练，会占用计算资源。日常文档整理和清理不启动它；修改其生命周期逻辑使用轻量模拟测试。

## 架构维护

- 修改模型输入、FPS、特征、归一化或 checkpoint 契约时，同步更新 [架构文档](ARCHITECTURE.md) 和相应兼容性测试。
- 严格区分“当前已实现”“目标设计”“已实测”；离线 `semantics` 已实现，在线会话实现前不将 `react` 写成可运行命令。
- 正式架构由数据/几何、模型/扩散、训练、生成、理解、评估组成；共享 CVAE 与未来会话的职责按主架构文档维护。
- 实验结果写报告，稳定结论再提炼进主文档，避免主文档变为不断追加的日志。
- 新增报告写入 [报告索引](reports/README.md)；自动 smoke 报告按唯一运行目录发现，无需修改共享索引。
- 文档移动后检查相对链接、复现命令及源码引用。正式训练路径保持稳定，避免影响在运行的任务。
